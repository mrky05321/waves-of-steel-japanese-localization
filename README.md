# Waves of Steel 日本語化

このリポジトリは、PC版 *All Or Nothing: Waves of Steel* 向けの非公式日本語化プロジェクトです。ゲーム本体のファイルは配布せず、セーブデータも変更しません。適用時はインストール済みゲームの一部データを書き換え、復元用の原本をローカルに保存します。

## 翻訳範囲

メニュー、HUD、設定・設計画面の案内、キャンペーン／フリープレイのミッション名と表示目標、会話・チュートリアル・スクロール形式のストーリー、艦船・部品・航空機・建物の名称や説明、技術ツリーの説明、ロード中のヒント、クレジットなどを日本語化しています。長いストーリー文には、表示領域に収まるよう本文側に改行を入れています。

内部条件だけに使う非表示目標、開発用テストミッション／テスト会話、画像に直接描かれた文字などは対象外です。

翻訳カタログには英語の原文を照合キーとして収録せず、位置とSHA-256ハッシュで対象を識別します。JSONデータはレコード番号とフィールド、CSVは行と列、ミッション定義はファイル内のフィールド位置、DLLはメソッド内の命令位置、Unity画面文はアセットIDとフィールド位置、会話フローはファイル内の行・文字位置で指定します。対象のハッシュが対応する既知版と一致しない箇所は書き換えを止めます。level1は通常版と設定変更前の既知版を受け付け、ローカルバックアップには実ファイルのハッシュを記録します。

## 英語のまま残している箇所

すべての文字列を置き換えると、ゲーム内の照合処理に影響する場合があります。たとえば ships.json の shipCategoryName は Continue 後のメニュー判定にも使われるため、英語のまま維持しています。また、技術ツリーや部品一覧の一部カテゴリ名は内部の識別・照合に結びついているため、現状は翻訳対象にしていません。

ゲーム側で生成される文字列や画像内文字など、翻訳データから安全に差し替えられない英語が残る場合があります。一定時間エリア内にとどまる目標表示は、ケツァルコアトルのステージで日本語表示を確認しています。

## 適用方法

適用スクリプトは、開発者の現在のゲームインストールに合わせて作成しています。ゲームを終了してから JapaneseLocalization フォルダー内の apply-japanese.bat を起動し、1 で適用、2 で復元します。PowerShell 7 があれば優先して使用し、なければ Windows 標準の Windows PowerShell 5.1 を使用します。通常は追加の PowerShell のインストールは不要です。JapaneseLocalization はゲーム本体フォルダーの直下に置きます。

### GitHubから取得する場合の注意

このGitHubリポジトリやZIPには、ゲームの原本ファイルを含めていません。Steam版ゲーム本体がインストール済みで、対象ファイルが対応する未改変版なら、初回起動時に適用スクリプトが必要な原本ファイル（約176 MiB）のハッシュを確認し、一致したファイルだけをローカルの backup フォルダーへコピーします。原本ゲームデータはアップロードされません。

バックアップが作成される前に、対象ファイルすべてが対応する既知ハッシュと一致することを確認します。ゲームの更新や他の改変などでハッシュが異なる場合は、バックアップもゲームデータも変更せず停止します。バックアップの作成に失敗した場合も、ゲームデータには適用しません。作成したバックアップは復元にも使われ、再適用のためにローカルに残ります。

## コマンドラインのオプション

ゲーム本体フォルダーからスクリプトを実行できます。通常適用、復元のほか、JSON/CSVとミッション定義だけを適用する DataOnly、メニュー項目とメインメニュー用フォント設定だけを適用する MenusOnly、会話・チュートリアル・スクロールストーリーだけを適用する FlowOnly があります。詳細は apply-japanese.ps1 のパラメーターを参照してください。

## ゲーム更新について

ゲーム更新で対象ファイルが変わると、原本ハッシュや想定した表示データとの照合に失敗することがあります。その場合は無理に上書きせず停止します。新しいゲーム版への対応には、翻訳カタログと適用対象の再確認が必要です。
