Waves of Steel 日本語化プロジェクト

このリポジトリには日本語化データと適用スクリプトを含みます。ゲーム本体のファイルは含まず、セーブデータも変更しません。適用時はインストール済みゲームの一部データを書き換え、復元用の原本をローカルに保存します。

【このフォルダーの適用手順】
開発者のローカルゲーム環境向けです。ゲームを終了し、apply-japanese.bat を起動します。
1 で日本語化、2 で復元します。PowerShell 7 があれば優先して使用し、なければ Windows 標準の Windows PowerShell 5.1 を使用します。通常は追加の PowerShell のインストールは不要です。
JapaneseLocalization フォルダーをゲーム本体フォルダーの直下に置いてください。

翻訳カタログには英語の原文を照合キーとして収録せず、JSON/CSVの行・フィールド、ミッション内の位置、DLL命令位置、UnityアセットIDとフィールド位置、会話フローの行・文字位置で対象を指定します。原文SHA-256ハッシュが対応版と一致しない箇所は書き換えません。

【GitHubから取得する場合】
GitHubには原本ゲームデータを含めていません。Steam版ゲーム本体があり、対象ファイルが対応する未改変版なら、
初回起動時に必要な原本ファイル（約176 MiB）のハッシュを検証してからローカルにバックアップします。
ハッシュが異なる場合はバックアップもゲームデータも変更せず停止します。詳細は README.md を参照してください。

翻訳範囲、残している英語、オプションの詳細は README.md を参照してください。
